# Phase 3 experiment directory

No participant data is ever stored in this repository or its private
companion repo. Participant data lives in Airtable only.

This directory holds agent prompts, evaluator runs, and signal outputs.
See phase3-agents-and-loop.md and phase3-signal-map.md in the project
knowledge base for the full specification.

Operational work on the live research experience is governed by
`/research/agent-workflow.md` and `/research/work-state.json`. It runs on
demand and is independent of the main-site sprint cadence and sprint state.
