# Private research notes — not published

This directory holds internal pattern-review reports from the
`research-pattern-analyst` subagent (see `.claude/agents/`). These are
working notes, not articles: raw hypothesis logs, re-identification
checks, and honest "not yet testable" outcomes at low sample sizes.

This directory is excluded from deployment via `.vercelignore` at the
repo root — nothing here is ever fetchable from the live site, unlike
the rest of this repo (which Vercel serves as static files with no
other access control).

If a finding here becomes strong enough to write about, it goes through
a separate editorial step and, only then, becomes a new article under
`content/learnings/`.
